# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### Types of changes

These section headings are used under each release.<br>A heading is only included when it has at least one entry.

- `Added` — New content or capability that was not present before.
- `Changed` — Updates to existing behavior or content that is not a simple bug fix.
- `Deprecated` — Still present, but planned for removal.
- `Removed` — Content or behavior that is removed as of this release.
- `Fixed` — Corrections to bugs, broken assets, or incorrect behavior.
- `Security` — Changes that address a vulnerability or reduce a security risk.
